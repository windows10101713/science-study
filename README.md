# Science Study

**기초부터 전문가 수준까지, AI와 함께 과학을 탐구하는 개인화 학습 플랫폼**

과학 개념을 읽는 데서 끝나지 않고, 자신의 수준에 맞는 설명과 문제 풀이를 반복하며 이해도를 높인다. 학교 교육과정의 복습을 지원하면서도 사용자가 원하는 교육과정 밖의 주제와 고급 과학까지 이어서 학습할 수 있도록 설계한다.

### 현재 개발 목표

| 항목 | 1차 목표 |
| --- | --- |
| 첫 지원 과목 | 중학교 물리 |
| 첫 콘텐츠 | 개념 10개, 문제 40개, 관찰 활동 10개 |
| 기본 언어 | 한국어 |
| 학습 방식 | 로그인 없이 가능한 10~15분 학습 세션 |
| 우선 검증할 가설 | 개인의 수준에 맞춘 설명과 오답 복습이 일반적인 정적 문제 풀이보다 학습 지속과 이해에 도움이 되는가 |

영어, AI 생성, 오프라인 동기화, 고급·전문가 탐구는 1차 학습 흐름이 검증된 뒤 단계적으로 추가한다.

---

## 1. 해결하려는 문제

과학 학습자는 다음과 같은 어려움을 겪는다.

- 같은 개념도 자신의 학년과 배경지식에 따라 설명 난이도가 달라야 한다.
- 설명을 읽은 뒤 실제로 이해했는지 확인하기 어렵다.
- 틀린 문제를 다시 풀고 취약한 개념을 추적하는 과정이 끊기기 쉽다.

Science Study는 **학습 설정, 설명, 문제 풀이, 복습**을 하나의 짧은 학습 사이클로 연결한다.

---

## 2. 제품 차별화

Science Study는 교육과정의 내용을 디지털 문제집으로 옮기는 서비스가 아니다. 사용자의 현재 지식 수준과 관심사를 AI가 파악하고, 같은 과학 주제를 기초 설명부터 대학·연구 수준의 논의까지 이어 주는 **개인화 과학 학습 플랫폼**을 지향한다.

### 다른 학습 플랫폼과의 차이

- **교육과정에 갇히지 않는다**: 학교 진도와 무관하게 사용자가 궁금한 주제를 선택한다.
- **초급부터 전문가까지 연결한다**: 중학교의 힘과 운동에서 시작해 미적분 기반 역학, 라그랑주 역학, 수치 시뮬레이션까지 단계적으로 올라갈 수 있다.
- **설명 깊이를 조절한다**: 같은 개념을 직관적 비유, 수식 중심 설명, 대학 교재 수준, 논문 읽기 준비 수준으로 다시 설명한다.
- **답을 주는 대신 사고를 확장한다**: AI가 후속 질문, 반례, 실험 설계, 다른 분야와의 연결을 제안한다.
- **개인의 학습 경로를 만든다**: 시험 대비 점수만 관리하지 않고 선수 개념, 관심 분야, 오답, 탐구 목표를 바탕으로 다음 학습을 추천한다.

### 기존 플랫폼의 단점에 대한 해결책

| 기존의 한계 | Science Study의 해결 방법 | 검증 기준 |
| --- | --- | --- |
| 한국어 콘텐츠 부족 | 한국어를 기본 언어로 제공하고, 전문 용어는 한국어·영어를 함께 표시한다. 사용자가 원하면 같은 설명을 영어 원문 수준으로 전환한다. | 중학교 물리 레슨 10개와 문제 40개를 자연스러운 한국어로 제공하고, 핵심 용어에 영문 표기를 병기한다. |
| 가상 실험의 한계 | 시뮬레이션을 실제 실험의 대체물이라고 주장하지 않는다. 가정에서 가능한 안전한 관찰 활동, 기록, 결과 예측, 실제 실험과의 차이 분석을 함께 제공한다. | 각 개념에 관찰 활동 1개, 예측 질문 1개, 결과 기록 항목을 포함한다. 위험한 실험에는 전문가 감독과 안전 장비가 필요하다는 경고를 표시한다. |
| 인터넷 의존성 | 짧은 레슨과 이미 학습한 문제를 기기에 저장해 연결이 끊겨도 학습할 수 있게 한다. 동기화가 필요한 작업은 연결이 복구된 뒤 처리한다. | 마지막으로 연 레슨 10개와 문제 40개를 오프라인에서 열고 풀 수 있으며, 재연결 후 풀이 기록을 동기화한다. |
| 개인화 부족 | 첫 진단에서 수준·선수 지식·관심사·목표를 받고, 답안·풀이 시간·오답 원인을 이용해 다음 설명 깊이와 문제 난이도를 조절한다. | 같은 개념을 기초·교육과정·대학 초급 설명으로 제공하고, 3문제 이상 연속 정답이면 난이도를 한 단계 올린다. |
| 심화 기능의 비용 부담 | 핵심 개념, 기본 문제, 오답 복습은 무료로 유지한다. 고급 기능에 비용이 발생하더라도 학습 기록 내보내기와 기본 콘텐츠를 제한하지 않는다. | 로그인한 사용자는 무료로 레슨 10개, 문제 40개, 오답 노트, 기본 AI 설명을 사용할 수 있다. 유료화는 실제 운영 비용을 확인한 뒤 별도로 결정한다. |

이 원칙에 따라 Science Study는 기존 플랫폼을 단순히 복제하지 않고, **한국어 기반의 개인화·탐구 중심·부분 오프라인 과학 학습**을 제공한다. 다만 온라인 서비스가 실제 실험실, 교사, 전문 연구 장비를 완전히 대체할 수 있다는 식으로 과장하지 않는다.

### 다국어 지원

한국어를 기본 언어로 시작하되, 영어를 첫 번째 추가 언어로 지원하고 콘텐츠 구조는 다른 언어를 추가할 수 있게 설계한다. 번역은 단순히 화면 문구만 바꾸는 기능이 아니라 과학 용어와 설명의 의미를 보존하는 학습 기능으로 취급한다.

- 사용자가 앱 언어와 학습 콘텐츠 언어를 각각 선택할 수 있게 한다.
- AI 설명·문제·해설은 선택한 언어로 생성하고, 답변 언어가 임의로 바뀌지 않도록 요청에 언어 코드를 포함한다.
- 과학 용어는 `한국어 표기`, `영어 원어`, `정의`, `발음 또는 약어`를 하나의 용어 사전에서 관리한다.
- 번역된 콘텐츠는 사람이 검수하며, 수식·단위·변수명·화학식·고유명사는 번역 과정에서 변경하지 않는다.
- 아직 번역되지 않은 레슨은 기본 언어로 제공하되, 사용자에게 현재 표시 언어를 명확히 알린다.
- 언어별 문장 길이와 날짜·숫자·단위 표기를 고려해 화면이 겹치지 않도록 테스트한다.
- 초기 지원 언어는 한국어와 영어로 제한하고, 사용 데이터와 검수 인력이 확보된 뒤 일본어·중국어 등으로 확장한다.

콘텐츠 ID와 번역본을 분리해 하나의 개념에 여러 언어 버전을 연결한다. 예를 들어 `physics-middle-01`은 공통 개념 ID이고, `ko`, `en`은 각각의 제목·설명·문제·해설을 가진 번역본이다.

```text
Concept: physics-middle-01
├── ko: 힘의 의미
└── en: Meaning of Force
```

### 학습 수준

| 수준 | 학습 목표 | AI의 역할 |
| --- | --- | --- |
| 기초 | 일상 현상과 핵심 용어 이해 | 쉬운 말, 그림에 가까운 예시, 기초 확인 문제 제공 |
| 교육과정 | 중·고등학교 개념과 시험 유형 습득 | 교과 개념 정리, 단계별 풀이, 오답 분석 |
| 대학 | 수식과 전공 개념을 사용해 설명 | 선수 수학·과학 개념 확인, 유도 과정과 응용 문제 제공 |
| 고급 | 여러 이론을 비교하고 모델을 적용 | 심화 수식, 가정과 한계, 수치 예제, 반례 제시 |
| 전문가 | 최신 연구를 읽고 스스로 질문 생성 | 논문·데이터의 핵심 요약, 연구 주제 연결, 검증할 가설과 실험 설계 보조 |

전문가 수준의 기능은 AI가 연구 결과의 진위를 보증한다는 뜻이 아니다. 출처, 불확실성, 모델의 가정과 한계를 함께 제시하고, 사용자가 원문과 1차 자료를 확인하도록 돕는 것을 목표로 한다.

---

## 3. 목표 사용자

- 중학생부터 전문가·연구 입문자까지의 과학 학습자
- 물리학, 화학, 생물학, 지구과학, 천문학을 기초부터 심화까지 공부하려는 사용자
- 긴 강의보다 10~15분 단위의 반복 학습을 선호하는 사용자

초기 버전에서는 중학교 1학년부터 고등학교 3학년까지를 우선 지원한다. 이후 학년 대신 `기초`, `대학`, `고급`, `전문가` 수준을 선택할 수 있도록 확장하고, 관심 과목·선수 지식·학습 목표를 함께 입력받는다.

---

## 4. 핵심 학습 흐름

```text
과목·학년·수준 선택
	↓
개념 선택 또는 오늘의 학습 시작
	↓
수준에 맞는 개념 설명
	↓
개념 확인 문제 3~5개 풀이
	↓
정답·해설·오답 원인 확인
	↓
취약 개념 저장 및 다음 복습 일정 제안
```

한 번의 학습 세션은 다음 조건을 만족한다.

- 소요 시간: 10~15분
- 설명: 핵심 개념, 쉬운 예시, 자주 하는 오해를 포함
- 문제: 객관식 2개, 단답형 1개, 응용 문제 1개를 기본으로 제공
- 종료 시: 점수, 틀린 개념, 다음 추천 학습을 표시

## 5. 사용자 시나리오

### 중학생 (기초 수준, 학교 복습)

```
Session 1: 로그인 없이 '중학교 물리' → '중1' → '기초' 선택
         → "힘의 의미" 개념 설명 (쉬운 예시, 일상 경험 중심)
         → 객관식 문제 2개, 단답형 1개, 응용 1개 풀이 (11분)
         → 정답률 75% → "자유낙하" 복습 추천
Session 2 (다음날): 저장된 "자유낙하" 개념 복습
         → 이전 오답을 다시 확인한 후 새로운 문제 풀이
         → 정답률 90% → 차단 해제, "뉴턴의 법칙" 추천
```

### 고등학생 (교육과정 수준, 심화 공부)

```
Session 1: 로그인 → "중학교 물리" → "대학 초급" 수준 선택
         → 같은 개념 "힘의 의미"를 벡터·미분 형식으로 설명
         → 수식 중심 문제 풀이 (유도 과정 포함)
         → 정답률 60% → "미분의 물리적 의미" 선수 개념 제시
```

### 과학 애호가 (전문가 수준, 탐구)

```
Session 1: 로그인 → "사용자 정의 탐구" → "우주의 팽창 속도"라고 질문
         → 허블 상수 정의, 관찰 증거, 최신 측정값 제시
         → 출처 5개, 불확실성 ±2% 표시
         → 다음 질문 제시: "암흑에너지는 무엇인가?"
         → 사용자가 선택하면 필요한 선수 개념과 실험 설계 제안
```

## 6. MVP 범위

### 반드시 구현할 기능

1. **학습 설정**
   - 과목, 학년, 난이도, 학습 시간을 선택한다.
2. **개념 학습**
   - 미리 등록한 개념 목록에서 주제를 선택한다.
   - 초기 버전은 등록된 설명을 보여주고, 이후 AI가 선택한 수준에 맞춰 설명을 생성한다.
3. **문제 풀이**
   - 개념별로 3~5개의 문제를 제공한다.
   - 정답뿐 아니라 풀이 과정과 오답 이유를 보여준다.
4. **학습 결과**
   - 정답률과 개념별 이해 상태를 기록한다.
   - 틀린 문제를 오답 노트에 저장한다.
5. **복습 추천**
   - 오답 개념과 낮은 정답률의 개념을 다음 학습 대상으로 추천한다.
6. **한국어 콘텐츠와 용어 병기**
   - 설명과 문제는 한국어로 제공하고, 핵심 전문 용어에는 영어 원어를 함께 표시한다.
7. **관찰·탐구 활동**
   - 각 레슨에 위험하지 않은 관찰 활동, 예측 질문, 결과 기록을 하나 이상 포함한다.
8. **학습 기록 임시 저장**
   - 로그인 전에도 현재 세션의 답안과 진행 상태를 브라우저에 임시 저장한다.

### MVP에서 제외할 기능

- 실시간 음성 튜터
- 이미지·손글씨 문제 인식
- 사용자 간 경쟁, 친구 기능, 랭킹
- 모든 과학 과목의 전체 교육과정 지원
- AI가 생성한 내용을 사람의 검수 없이 자동으로 학습 자료로 확정하는 기능

처음에는 과목 하나를 골라 완성한 뒤 다른 과목으로 확장한다. 추천 시작 과목은 개념과 문제의 구조가 비교적 명확한 **중학교 물리**다.

| 버전 | 포함 기능 | 완료 조건 |
| --- | --- | --- |
| v0.1 학습 흐름 | 한국어 정적 레슨, 문제 풀이, 채점, 결과, 오답 저장 | 로그인 없이 10~15분 세션을 끝까지 완료하고 새로고침 후 진행 상태를 복원한다. |

## 8. AI 사용 원칙

AI는 학습 보조 역할을 하며, 정답과 교육과정의 기준을 대신 결정하지 않는다. 동시에 교육과정에 없는 주제도 사용자의 수준에 맞춰 탐구할 수 있도록 설명자, 질문 생성기, 토론 상대, 탐구 설계 보조 역할을 수행한다.

- 모든 문제는 `과목`, `학년`, `단원`, `난이도`, `정답`, `해설` 필드를 가진 구조화된 형식으로 생성한다.
- 객관식 문제는 정답을 1개만 갖도록 검증한다.
- 설명과 해설에는 근거가 불명확한 수치나 사실을 포함하지 않는다.
- 생성 결과가 형식 검증에 실패하면 사용자에게 보여주지 않고 다시 생성하거나 미리 준비한 문제를 사용한다.
- 같은 세션에서 같은 문제를 반복 생성하지 않도록 문제 ID와 생성 이력을 저장한다.
- AI가 생성한 문제는 초기 운영 단계에서 사람이 표본 검수한다.
- 고급·전문가 수준의 답변에는 사용한 정의, 가정, 출처, 불확실성을 표시한다.
- 최신 연구나 논문을 언급할 때는 확인 가능한 출처를 제공하고, 출처를 확인하지 못한 내용은 사실처럼 단정하지 않는다.
- 사용자가 더 깊은 설명을 요청하면 `직관적 설명 → 수식 → 유도 과정 → 적용 사례 → 한계와 반례` 순서로 깊이를 확장한다.
- AI의 답변을 그대로 외우게 하기보다 “왜 그런가?”, “어떤 조건에서 깨지는가?”, “어떻게 검증할 것인가?”를 묻는 후속 질문을 생성한다.

### 문제 생성 입력 예시

```json
{
  "subject": "physics",
  "grade": 8,
  "unit": "힘과 운동",
   "difficulty": "basic",
   "learningLevel": "curriculum",
   "depth": "conceptual",
   "language": "ko",
  "questionTypes": ["multiple_choice", "short_answer", "application"],
  "count": 4
}
```

## 9. 기본 데이터 모델

초기 구현에서는 다음 데이터만 관리한다.

- `User`: 학년, 선호 과목, 수준
- `Concept`: 과목, 단원, 개념명, 핵심 키워드, 선수 개념
- `Question`: 문제, 선택지, 정답, 해설, 난이도, 출처 또는 검수 상태
- `Attempt`: 사용자, 문제, 제출 답안, 정답 여부, 풀이 시간
- `ReviewItem`: 오답 개념, 마지막 풀이 날짜, 다음 복습 날짜
- `LearningProfile`: 학습 수준, 선수 지식, 관심 분야, 학습 목표
- `Source`: 출처 유형, 제목, 저자, 링크, 확인 날짜, 신뢰도 메모
- `Translation`: 콘텐츠 ID, 언어 코드, 번역된 제목·설명·문제·해설, 검수 상태
- `Term`: 개념 용어, 언어별 표기, 정의, 영어 원어, 약어

정답률은 다음처럼 계산한다.

```text
정답률 = 정답으로 제출한 문제 수 / 전체 제출 문제 수 × 100
```

## 10. 화면 구성

1. **홈**: 오늘의 추천 학습, 최근 정답률, 복습할 개념
2. **학습 설정**: 과목·학년·난이도·학습 시간 선택
3. **개념 설명**: 설명, 예시, 핵심 용어, 이해 확인 버튼
4. **문제 풀이**: 문제, 답안 입력, 제출, 남은 문제 수
5. **결과**: 점수, 해설, 오답 개념, 복습 시작 버튼
6. **오답 노트**: 틀린 문제와 개념별 복습 목록
7. **탐구 모드**: 교육과정 밖의 질문을 입력하고 AI와 가설·근거·실험 방법을 단계적으로 검토
8. **깊이 조절**: 같은 주제를 직관, 수식, 대학, 고급 수준으로 전환

## 12. 개발 순서

### 1단계: 학습 흐름 고정

- 중학교 물리의 개념 10개를 정적 데이터로 등록한다.
- 설명 화면, 문제 풀이 화면, 결과 화면을 연결한다.
- AI 없이도 한 세션을 끝까지 완료할 수 있게 만든다.

### 2단계: 기록과 복습 추가

- 사용자별 풀이 결과를 저장한다.
- 정답률과 오답 노트를 표시한다.
- 정답률이 70% 미만인 개념을 복습 대상으로 추천한다.

### 3단계: AI 기능 연결

- 수준별 설명 생성
- 구조화된 문제 생성
- 생성 결과 검증 및 실패 시 재시도
- 생성 문제의 검수 상태 관리

### 4단계: 과목 확장

- 화학, 생물학, 지구과학 순서로 개념 데이터를 추가한다.
- 과목마다 다른 문제 유형이 필요한지 검토한다.

### 5단계: 고급·전문가 학습 확장

- 학년 선택과 별도로 학습 수준과 선수 지식 프로필을 지원한다.
- 수식 렌더링, 그래프, 간단한 수치 시뮬레이션을 추가한다.
- 논문·공개 데이터 등 확인 가능한 출처를 연결한다.
- AI가 제시한 설명의 가정, 불확실성, 반례를 표시한다.
- 답변 정확도뿐 아니라 출처 확인률, 후속 질문 해결률, 탐구 완료율을 측정한다.

## 13. 완료 기준

MVP는 다음 시나리오를 성공하면 완료로 본다.

- 신규 사용자가 1분 안에 과목과 학년을 선택할 수 있다.
- 사용자가 15분 안에 개념 1개와 문제 4개를 학습할 수 있다.
- 제출 직후 정답, 해설, 오답 이유를 확인할 수 있다.
- 학습 종료 후 정답률과 취약 개념이 저장된다.
- 같은 브라우저에서 다시 접속했을 때 현재 세션의 진행 상태가 복원된다.
- AI 없이도 등록된 레슨과 문제만으로 학습 세션을 완료할 수 있다.

### 테스트 항목

- 문제를 모두 맞혔을 때 정답률이 100%로 계산되는가
- 일부 문제를 틀렸을 때 해당 개념이 오답 노트에 저장되는가
- 문제 생성 결과에 선택지 2개 또는 정답 2개가 있으면 거부되는가
- 새로고침 후에도 학습 결과가 유지되는가
- 모바일 화면에서 문제와 답안 입력 영역이 겹치지 않는가
- 인터넷 연결을 끊은 상태에서 저장된 레슨과 문제를 열고 풀이할 수 있는가
- 재연결 후 오프라인 풀이 기록이 중복 없이 서버에 동기화되는가
- 한국어 설명에서 핵심 전문 용어의 영어 원어를 확인할 수 있는가
- 관찰 활동이 실제 실험을 대체한다고 오해하지 않도록 안전 안내가 표시되는가

가장 먼저 할 일은 기술 스택을 크게 확정하는 것이 아니라, **중학교 물리 개념 10개와 문제 40개를 준비하고 AI 없이 학습 사이클을 완성하는 것**이다. 이 흐름이 실제로 사용 가능한지 확인한 뒤 AI 생성을 연결한다. 이후 같은 개념을 교육과정 수준과 대학 초급 수준으로 다르게 설명하는 비교 실험을 진행해 개인화 학습의 효과를 확인한다.

## 17. 기술 스택

MVP에서는 직접 운영해야 하는 서버를 최소화하고, 학습 흐름과 데이터 구조를 검증하는 데 집중한다.

### 12.1 기본 선택

| 영역 | 기술 | 선택 이유 |
| --- | --- | --- |
| 프론트엔드 | React + TypeScript + Vite | 화면을 작은 컴포넌트로 나누고 타입으로 데이터 오류를 줄인다. |
| UI 스타일 | CSS Modules 또는 단일 전역 CSS | 화면 수가 적은 MVP에서 스타일 충돌과 의존성을 줄인다. |
| 오프라인 | PWA + Service Worker + IndexedDB | 최근 레슨과 미제출 풀이를 로컬에 보관해 연결이 끊겨도 학습을 이어 간다. |
| 언어 | 한국어 기본, 영어 추가, 언어 코드 기반 확장 | 번역 콘텐츠와 AI 응답의 언어를 일관되게 관리하고 과학 용어의 의미를 보존한다. |
| 클라이언트 상태 | React 기본 상태 관리 | 전역 상태 라이브러리는 학습 기록이 복잡해질 때 도입한다. |
| 백엔드 API | Node.js + TypeScript | 프론트엔드와 같은 언어를 사용해 타입과 검증 로직을 공유한다. |
| 데이터베이스 | PostgreSQL | 사용자, 개념, 문제, 풀이 기록 사이의 관계를 명확하게 관리한다. |
| 인증 | Supabase Auth 또는 검증된 인증 라이브러리 | 비밀번호를 직접 저장하지 않고 세션과 비밀번호 해싱을 위임한다. |
| 데이터 접근 | Supabase Client 또는 Prisma | MVP에서는 단순한 CRUD를 우선하고, 복잡한 서버 로직이 필요할 때 Prisma를 사용한다. |
| 콘텐츠 | `data/lessons/*.json` 또는 `data/lessons/*.ts` | 첫 단계에서는 레슨을 버전 관리하고 코드 리뷰할 수 있게 정적 파일로 관리한다. |
| 테스트 | Vitest + React Testing Library | 정답률 계산, 문제 검증, 주요 화면 동작을 빠르게 검증한다. |
| 코드 품질 | ESLint + Prettier | 커밋 전 타입 오류와 포맷 불일치를 줄인다. |

기본 배포 조합은 **Vercel(프론트엔드) + Supabase(인증·PostgreSQL) + 서버 측 API 함수**로 한다. 사용자가 늘거나 서버 작업이 복잡해지면 API를 별도 Node.js 서버로 분리한다.

### 12.2 화면 설계 원칙

- 한 화면에는 하나의 주 행동만 둔다. 예: 학습 설정, 답안 제출, 복습 시작
- MVP 화면은 홈, 학습 설정, 개념 설명, 문제 풀이, 결과, 오답 노트 6개로 제한한다.
- 문제 풀이 화면에는 현재 문제 번호, 답안 영역, 제출 버튼을 항상 같은 위치에 둔다.
- 모바일 너비 360px부터 데스크톱까지 사용할 수 있도록 반응형으로 만든다.
- 학습 중에는 불필요한 메뉴를 숨기고, 뒤로 가기·나가기 시 진행 상태를 처리한다.

### 12.3 데이터와 보안

- 비밀번호 원문은 애플리케이션 데이터베이스에 저장하지 않는다.
- `SUPABASE_URL`, `SUPABASE_ANON_KEY`, AI API 키 등 비밀값은 `.env`에 두고 저장소에 커밋하지 않는다.
- 브라우저에는 공개 가능한 키만 노출하고, AI API 키와 관리자 키는 서버에서만 사용한다.
- 모든 학습 기록 조회·수정 요청에는 로그인한 사용자 ID를 사용한다.
- PostgreSQL Row Level Security를 적용해 사용자가 자신의 `Attempt`, `ReviewItem`만 조회·수정하게 한다.
- 문제 정답은 제출 전까지 클라이언트에 보내지 않거나, 최소한 UI에 노출되지 않도록 한다.
- 입력값은 클라이언트와 서버 양쪽에서 검증하고, 오류 메시지에 비밀번호나 토큰을 포함하지 않는다.

### 12.4 레슨 콘텐츠 구조

`resson`이 아니라 `lesson`을 사용한다. 초기 레슨은 코드와 분리된 정적 데이터로 관리한다.

```text
data/
└── lessons/
      ├── physics-middle-01.json
      ├── physics-middle-02.json
      └── index.ts
```

레슨 하나는 다음 필드를 가진다.

```json
{
   "id": "physics-middle-01",
   "subject": "physics",
   "grade": 8,
   "unit": "힘과 운동",
   "title": "힘의 의미",
   "summary": "힘은 물체의 운동 상태나 모양을 바꾸는 원인이다.",
   "keywords": ["힘", "운동 상태", "변형"],
   "misconceptions": ["힘이 있어야만 물체가 계속 움직인다"],
   "questions": ["physics-middle-01-q01", "physics-middle-01-q02"]
}
```

레슨 파일에는 정답과 해설도 포함하되, 사용자에게 전달하는 API 응답에서는 제출 전 정답 필드를 제거한다. 콘텐츠가 100개 이상으로 늘어나거나 운영 중 직접 수정해야 할 때만 레슨을 데이터베이스로 이전한다.

### 12.5 API와 AI 호출 경계

프론트엔드가 데이터베이스나 AI 모델을 직접 호출하지 않고 서버 측 API를 거친다.

```text
React 화면
   ↓
서버 API
   ├── 레슨 조회
   ├── 답안 제출 및 채점
   ├── 학습 기록 저장
   └── AI 설명·문제 생성
          ↓
      구조화된 JSON 검증
```

최소 API는 다음과 같이 정의한다.

- `GET /api/lessons/:lessonId`: 정답을 제외한 레슨 조회
- `POST /api/attempts`: 답안 제출, 채점, 해설 반환
- `GET /api/reviews`: 로그인한 사용자의 복습 목록 조회
- `POST /api/reviews/:conceptId/complete`: 복습 완료 기록
- `POST /api/ai/explanations`: 서버에서만 AI 설명 생성
- `POST /api/ai/questions`: 서버에서만 AI 문제 생성

AI 기능은 3단계에서 추가한다. AI 응답은 Zod 같은 스키마 검증기로 검사하고, 실패하면 재시도하거나 정적 문제를 대신 사용한다. AI 호출에는 요청 횟수 제한과 타임아웃을 둔다.

### 12.6 권장 폴더 구조

```text
src/
├── components/       # 재사용 UI
├── pages/            # 화면 단위 컴포넌트
├── features/         # lesson, quiz, review 기능별 로직
├── lib/              # API 클라이언트, 인증, 검증기
├── types/            # User, Lesson, Question, Attempt 타입
└── styles/           # 전역 스타일
data/
└── lessons/          # 초기 정적 레슨
tests/
└── fixtures/         # 테스트용 레슨과 답안
```

### 12.7 단계별 도입 순서

1. React, TypeScript, Vite로 화면 6개와 정적 레슨 10개를 만든다.
2. 로그인 없이도 학습 세션을 끝까지 실행하고, 브라우저 로컬 저장으로 임시 결과를 기록한다.
3. Supabase Auth와 PostgreSQL을 연결하고 `Attempt`, `ReviewItem`을 저장한다.
4. 서버 API를 통해 채점과 복습 추천을 처리한다.
5. AI 설명·문제 생성을 추가하되, 정적 콘텐츠를 항상 대체 수단으로 유지한다.
6. 영어 번역본과 언어 선택을 추가하고, 번역되지 않은 콘텐츠는 기본 언어로 안내한다.
7. PWA 캐시와 IndexedDB를 추가하고, 오프라인 풀이를 재연결 후 한 번만 동기화한다.
8. 수식·그래프·출처 기반 탐구 모드를 추가한 뒤 고급·전문가 수준으로 확장한다.

### 12.8 기술 스택 완료 기준

- `npm run dev`로 로컬에서 학습 세션을 시작할 수 있다.
- `npm run build`, `npm run lint`, `npm test`가 모두 통과한다.
- 로그인하지 않은 사용자는 다른 사용자의 학습 기록을 조회할 수 없다.
- 서버 API가 정답을 제출 전 응답에 포함하지 않는다.
- AI 키가 브라우저 번들이나 Git 저장소에 포함되지 않는다.
- 레슨 JSON이 스키마 검증을 통과하지 않으면 빌드 또는 테스트에서 실패한다.
